One original fortune-cookie line for a software developer, written by a small
Node 22 TypeScript program (`main.ts`, standard library only, no dependencies)
for make.fun's "Fortune Cookie Wisdom for Developers" bounty.

> Ship on Friday, and the weekend will teach you what your tests could not.

## Run it

```sh
node main.ts
```

This writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`; falls back to `./output/entry.txt` when run by hand).
The line is 73 characters, a single line with no trailing newline.
